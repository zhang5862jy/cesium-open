# 标牌工具设计文档

## 目标与边界

工具面向 Cesium 三维和 OpenLayers 二维地图中的移动目标屏幕标牌。每个目标有独立文字、样式、偏移与显隐状态；三维共享 Worker、字形图集与实例化渲染资源，二维使用顶层 div 与 CSS transform。可选屏幕避让以拖动标牌为最高优先级，在有限空间内尽量消除重叠；空间不足时保留重叠目标。示例数量不是性能承诺；DOM 与 GPU 的开销不同，实际效果受文字长度、字体数量、分辨率与硬件影响。

开启避让后默认将自动位移限制在配置位置附近 160px 内。精确候选先减少与本次释放标牌的冲突，再减少总重叠，再比较本轮移动数量和移动代价；距离权重与历史拖拽优先级不能抵消碰撞。`distanceWeight` 仅调节靠近配置位置的偏好，设为 0 时仍保留靠近本次修复起点的偏好。手动拖拽形成的新位置继续作为首选位置；两张都曾拖动的标牌再次碰撞时，仍尽量只移动必要的一张。附近无满足约束的空位或搜索预算耗尽时保留重叠。自动位移半径与“中心到地理目标的最大距离”是独立约束。

避让移动只由标牌碰撞（含配置间距）触发。无碰撞时保留已有相对偏移，地图平移、缩放或旋转可以带着面板移出视口，边缘本身不会触发回拉。一次碰撞修复开始前完整位于视口内的标牌，修复结果须继续完整位于视口内；本次修复开始时已经越界的标牌没有强制入屏要求。此判定使用当前投影和已有偏移，不追溯上一帧是否在屏内。候选无法同时满足保护与距离约束时保留重叠。

每次求解结果直接应用，不用过渡动画或分帧小步滑动；GPU / DOM 位置、牵引线与命中区域同步更新。求解内部的迭代预算只限制计算量，不是动画时长。

管理器默认在关闭避让时保留当前显示位置，将显示偏移保存为新的首选偏移。构造参数 `preservePositionOnAvoidanceDisable: false` 可改为恢复避让前的配置偏移。详标由独立标题行和多行正文组成；简标仍将字段值放在同一行。标题和简标左侧各显示属方色方块与每目标独立字母，固定、关闭小圆按钮仅在详标标题右侧显示；两种模式均保留悬停事件。

工具包不创建或销毁使用方的 Viewer / Map，不依赖 Vue，也不生成业务运动数据。示例负责本地底图、地图配置、平台/属方分类和控制面板。三维 route 为 /examples/primitive/target-callout，二维为 /examples/primitive/target-callout-2d；二维默认 120 个目标，可切换 30 / 120 / 300 / 1000，复用三维数据结构与字段处理函数。

## 对外对象

| 对象 | 职责 | 生命周期 |
| --- | --- | --- |
| TargetCalloutManager | 校验宿主二选一、创建句柄、合并更新、协调渲染与共享交互 | 使用方创建，Viewer / Map 销毁前 destroy |
| WorkerCalloutHandle | 一个目标的配置与操作入口 | 由管理器持有，不独立拥有 GPU 资源 |
| ScreenBatchRenderer | 将实例缓冲及目标投影提交给 Cesium | 由管理器销毁 |
| DomCalloutRenderer | 在 OpenLayers viewport 中管理 div、投影、测量及 transform | 管理器内部创建与销毁 |
| CalloutRenderer / CalloutInteractionHost | 声明后端配置与宿主交互边界 | 类型接口，具体资源由实现持有 |
| TargetCallout | 保留原生 Cesium 小批量实现 | 独立使用时由调用方销毁 |

现有公共导出保持兼容。新增内部类不直接作为稳定 API 导出，避免内部重构影响消费者。

`TargetCalloutSharedOptions` 声明通用配置，`TargetCalloutManagerOptions` 在其上约束 `{ scene, map?: never }` 或 `{ map, scene?: never }`。调用方只替换宿主，其他目标字段和句柄方法不变。二维自动使用 map.getViewport 作为标牌和悬停按钮容器，不要求额外 container。

共享交互包括选择、点击、双击、拖拽、悬停、固定和关闭。新增 onClick / onDoubleClick 同时用于二三维；双击先切换模式再通知业务，浏览器原生双击过程中的单击仍正常通知。拖拽暂时禁用宿主输入，释放或销毁时恢复。详标标题、正文和方块属于同一个拖拽与命中区域；标题右侧预留小圆按钮空间，按钮动作不触发地图或标牌拖拽。简标保留点击与悬停事件，不出现操作按钮。

## 样式规则

示例包含 11 种平台与 6 个属方，初始化用固定种子生成分类。平台控制字体 family、字号、是否加粗和是否斜体；粗体映射到 700，常规映射到 400。微软雅黑、宋体优先使用系统字体，未安装时按 CSS 字体栈回退。

属方为红、蓝、绿、粉、未分配、不明。后两者默认橙色；颜色参数分别控制文字、边框、牵引线、方块背景和方块字母。修改平台只更新同平台文字属性；修改属方只更新同属方颜色。恢复样式采用当前分类配置，而不是重新随机。三维示例为 detailed / compact / title 分别保存平台和属方配置；二维提供三套样式选择及同属方方块颜色编辑。

详标正文默认背景 rgba(255, 255, 255, 0.1)，行距 1px，内边距上/右/下/左为 10/10/10/5px。简标和详标标题各有独立默认样式；标题默认 14px、700 字重、4/6/4/6px 内边距。标题字体、颜色、背景与边框由 title 样式控制；牵引线由显示模式对应的正文或简标样式控制。标题和简标均为一行，方块不占用业务字段，字母默认 A，可按目标独立设置 A–Z。示例以 index % 3 分配 A/B/C，颜色使用对应样式的属方配置。标题和正文共同组成详标避让矩形，仍只有简标和详标两个碰撞组。三维示例的 16ms、二维示例的 200ms 都是业务数据提交间隔，不保证同间隔完成布局或每帧生成新文字。

二维文本用 textContent 插入 div，浏览器负责字体渲染与测量；三维使用 SDF。两者共享字号、颜色、边框、牵引线等样式含义，但不要求字体栅格化逐像素一致。smoothing / weight 是三维 SDF 参数，二维仅保留设置值；pixelSnap 可用于二维面板取整，拖拽或有限距离约束优先。

## 坐标与距离约束

公开 position 始终是 Cesium.Cartesian3 表示的 WGS84 ECEF，批量 positions 始终是 Float64Array。二维内部转换成经纬度和 View 投影，支持 OpenLayers 用户投影与最近世界副本；调用方不能把原位置数组直接替换为经纬度数组。二维不以高程移动屏幕锚点，不处理地球或三维建筑遮挡。二三维视口显隐同时检查投影锚点与偏移后的面板矩形：锚点出屏但面板仍与视口相交时继续显示，两者都离开才按离屏隐藏。三维相机前后关系与地球遮挡规则仍独立生效。

公开 offset 为目标点到标牌左下角的 CSS 像素偏移，X 向右、Y 向下。最大偏移限制使用中心点：

```text
centerX = offsetX + width / 2
centerY = offsetY - height / 2
distance = hypot(centerX, centerY)
```

超限时保持方向，将中心投影到限制圆周，再换算回左下角偏移。Infinity 表示不限；0 表示中心与目标重合。字号、文字和内边距改变后，渲染时使用当前宽高重新约束。屏幕固定与距离约束同时启用时，约束优先。

该中心距离限制是显式配置，仍独立作用于拖拽和偏移；它不意味着把标牌钳制在屏内。碰撞修复的屏内保护只适用于本次修复前已完整在屏内的矩形，不是所有标牌每帧都要满足的约束。面板越界部分由地图容器裁剪，锚点出屏不会提前隐藏仍与视口相交的面板。

## 更新与所有权

位置、标题、字母、正文和字段通过 updateTargets 更新，单目标配置通过句柄更新。同一个事件循环内的 patch 合并；三维布局 Worker 同时仅处理一批请求，二维在微任务调度边界统一应用 DOM 更新。完整位置批次保留最新值；稀疏 titles / badges / lines / fields 按目标索引合并，每目标最后一次提交优先，避免覆盖其他目标尚未处理的更新。输入先全部校验再入队。title 为单行字符串，也可读取 key 为 title 的字段值；同一批显式 titles 优先。badgeText 为单个英文字母，输入小写转大写，空值或多字符拒绝。

目标可配置唯一业务 id，通过 getById 查询；省略时使用初始数组索引。数量与索引在管理器生命周期内固定。句柄 setPosition/setLines 创建持续覆写，Worker 单独保留最新源数据；resetOverrides 清除指定覆写并立即恢复最近数据，不等待下一次业务推送。setTitle/setBadgeText 与批量标题、字母更新采用最近值，不建立该覆写层。示例将模拟首行移至 titles、正文保留五行，避免重复标题；示例手工标题通过暂停该目标的源标题推送保持，恢复时显式提交最近源值。

ready 表示首批数据应用完成（三维 GPU 上传，二维 DOM 内容与测量），flush 等待待处理队列排空，二者均不等同于浏览器已绘制一帧。后端失败后管理器释放所属资源并拒绝未完成的 Promise。业务回调异常不能阻断调度与 Promise 完成。

transfer=true 表示允许转移位置数组所有权；从提交起调用方不得继续读写或再次转移该数组，实际 detach 在处理批次时发生。默认复制位置，文字和字段始终复制。二维通过可转移 structuredClone 保留同一所有权约定。三维 Worker 返回的实例缓冲在主线程上传后回传复用，ImageBitmap 上传后关闭。管理器统一释放所属 Worker / GPU 或 DOM / 地图监听，但不会销毁外部地图。

## 兼容与限制

当前 GPU 路线使用 Cesium 内部渲染 API，升级 Cesium 需跑视觉回归。字形图集固定 4096×4096，超出当前字符容量会报错；逐行缓存通过 WeakMap 关联目标，颜色缓存有数量上限。透明物体的合成和建筑遮挡下的精确拾取不属于当前完整保证范围。自动避让使用有限预算的矩形分离约束迭代与密度退化；密度搜索前后加入有邻域和候选数量限制的真实矩形修复，避免局部可分开的标牌只接受密度近似。密度阶段权衡占用估计与移动代价，避免微小的估计收益引起大幅移动；这不同于精确阶段的碰撞优先比较。它不是完整 VPSC，也不保证任意矩形集合的全局最优装箱结果；本次释放位置优先受保护，其他标牌在本次修复的屏内保护、距离与碰撞要求无法同时满足时允许残留重叠。

当前 OpenLayers peer dependency 为 ^10.11.0。二维不需要标牌专用 Worker / OffscreenCanvas / WebGL，但需要 DOM 和可转移 structuredClone；DOM 数量及文字更新仍影响布局成本，不能承诺 1000 个同时可见详标的固定帧率。两种后端复用相同避让求解器，简、详标分别形成两个碰撞组，跨组重叠仍允许。
