# 标牌工具技术路线

## 已实现路线

1. **业务与显示解耦**：工具包接受统一 ECEF 位置、文字、字段与样式输入。三维示例在独立 Worker 模拟，二维示例复用同一模拟函数，每 200ms 提交数据；平台/属方分类在业务层维护。
2. **共享字形**：OffscreenCanvas 以固定 64px 生成字形，距离场保存在不透明 RGB 中；多字号通过布局缩放复用字形。字体或粗斜体改变时生成缺失字形。
3. **批量实例化**：每个矩形/字符写入 16 个 float 的实例记录，共享 GPU 缓冲与图集。两个有序命令分别处理牵引线与面板，减少每目标独立对象开销。
4. **相机逐帧更新**：目标位置投影及标牌偏移通过小型目标参数纹理传给着色器，业务更新与相机响应分离。
5. **按需计算**：仅位置/显隐变化跳过文字布局和字符缓冲上传；未变化行复用测量；TypedArray 往返复用；默认无距离限制时跳过中心距离计算。
6. **可维护封装**：管理器作为公开门面，业务调度、分类配置、监控、图集缓存各由独立类负责；着色器和样式资源单独存放。
7. **屏幕避让**：仅因标牌碰撞移动，复用前帧相对偏移。精确候选按释放标牌冲突、总重叠、移动数量和移动代价的顺序选择，历史拖拽优先级和 distanceWeight 不抵消碰撞。无碰撞时允许随地图越界，不自动回位或进行视口钳制。只有本次碰撞修复开始前完整在屏内的标牌，才保护其不被修复推出；开始时已经越界者不被强制拉回。拖拽期间暂停整批避让，松手后按最终位置求解并直接落位，无过渡动画。空间哈希、候选去重和迭代预算控制开销，超密集场景在占用密度积分表搜索前后加入有界的精确局部修复；仍属近似启发式，不是完整 VPSC 或全局最优求解。无满足保护及距离约束的空位或预算耗尽时保留冲突。管理器关闭避让默认保留当前位置，设置 `preservePositionOnAvoidanceDisable: false` 才恢复既有配置偏移。
8. **简详标与标题**：详标由独立 title 行和多行 lines 正文组成，简标按业务处理函数将字段值合为一行；双击可切换。detailed / compact / title 三套样式独立保存，避让仍只有两种显示模式，按已上传批次的完整尺寸分组求解，跨模式允许重叠。标题和简标左侧显示属方色正方形及各目标独立的 badgeText 字母，方块颜色分别读取标题或简标样式。标题右侧预留小圆按钮区域，只有请求模式与已渲染模式均为详标时显示共享工具栏，简标继续触发悬停事件。
9. **二三维统一入口**：TargetCalloutManager 接收 scene 或 map，类型及运行时要求二选一。CalloutRenderer 声明后端配置接口，CalloutInteractionHost 声明投影后的事件宿主边界；同一份句柄和 drag / click / hover 控制器提供选择、点击、双击、拖拽、固定及关闭。
10. **二维 DOM 分支**：OpenLayers 10.11 viewport 顶层容器放置目标点、牵引线及面板 div，用 transform 更新偏移与线方向。保持 ECEF 业务数据，内部转换 View / 用户投影与最近世界副本；高程不参与二维锚点投影。内容/样式集中写入后统一测量，位置投影按版本缓存，不启动布局 Worker 或分配标牌 GPU 资源。
11. **跨后端资源边界**：ready / flush、覆写恢复、输入复制与 transfer=true 所有权约定一致。二维同步配置接口保留 smoothing / weight，但浏览器字体不使用 SDF 参数；pixelSnap 在满足拖拽和距离约束时对齐。destroy 释放工具自身资源，外部 Scene / Map 由调用者继续持有。

## 构建与验证

```bash
pnpm build
pnpm test:target-callout
pnpm --dir packages/cesium-screen-callout pack --pack-destination ../..
```

构建包括工具包 Vite 打包、类型声明、Vue 类型检查和站点构建。效率检查使用模拟 Canvas，验证缓存与重新生成的几何结果、Unicode、样式变更、仅位置/显隐更新，以及跳过 GPU 上传的路径。它不能替代真实字体和 WebGL 视觉测试。

在 /examples/primitive/target-callout 手工检查：11 类平台切换、6 属方颜色、正文/简标/标题三套字体与颜色独立配置、简详标双击切换、标题不在正文重复、每目标 A/B/C 字母修改与属方色方块、详标标题小圆按钮与简标无按钮、0/有限/无限中心距离、拖拽暂停避让与松手重算、关闭避让保留位置、固定后目标运动、暂停后相机操作、离开后重新进入。检查控制台及 Worker 错误。

在 /examples/primitive/target-callout-2d 手工检查：30 / 120 / 300 / 1000 数量切换、暂停后地图平移/缩放/旋转、标题与正文整体 transform / 命中 / 避让范围一致、定位/总览、点击/双击事件、拖拽时地图输入暂挂与恢复、三套独立样式与两组避让、A/B/C 独立字母和同属方方块色修改、小圆按钮定位及简标无按钮、关闭后恢复显示、固定、标题编辑与正文备注恢复、离开重进的容器和事件清理。底图仅加载两张本地 NaturalEarthII 半球图片，不应发出外部瓦片请求。

二三维都需覆盖碰撞前状态不同的边缘用例：无碰撞标牌随地图移动越界仍保持相对偏移；锚点出屏但面板仍与视口相交时继续显示，两者都离屏才隐藏；固定面板不因锚点单独出屏而消失；本次修复开始前完整在屏内的标牌不会被修复推出；本次修复前已越界者不会被强制拉回；单次求解结果直接应用，命中区域无动画滞后。上一帧在屏内、当前投影后已越界的标牌应归入“本次修复前已越界”，避免把条件保护错误实现为历史固定约束。三维仍验证地球遮挡与相机后方隐藏。

`/scripts/target-callout-manager-regression.html` 使用真实 Worker/GPU 检查队列、按需渲染和三轮创建/销毁；`/scripts/target-callout-camera-regression.html` 检查投影、文字、前后深度与混合像素。分段绘制让两个命令的实例处理次数从合计 2N 降为 N，继续保留先线后面板的顺序。独立 `cesium-screen-callout/worker` 入口隔离主线程 Cesium 依赖。

`/scripts/target-callout-2d-regression.html` 使用真实 OpenLayers 和 DOM，检查投影及世界循环、尺寸与 transform、覆写恢复、文本安全插入、共享点击/拖拽/工具栏行为及三轮清理，并统计没有标牌 Worker / WebGL 分配。它还构造两张都已完成拖拽的标牌再次碰撞，要求单次绘制内分开、只移动一张，并同步 DOM 和命中区域；后续静止帧保持布局。两套回归分别覆盖对应后端。

性能对比需保持浏览器、窗口分辨率、DPR、视角、可见数量、文字内容和更新间隔一致。分别记录布局、上传、往返延迟、rAF FPS/P95 和长任务。只在真实场景测得结果后报告收益；JS 堆不包含全部 GPU 和 Worker 内存。

二维性能应另外记录 DOM 内容更新、测量与 transform 成本；不能把三维 Worker / GPU 时间套用到二维，也不能把源数据中 1000 个目标等同于视口同时显示 1000 张标牌。二三维字体测量可能不同，验证样式含义与命中/避让一致，不能假定两种字体栅格化逐像素相等。

## 后续演进（尚未实现）

| 优先级 | 方向 | 前提与验收 |
| --- | --- | --- |
| 高 | 将现有浏览器回归接入 CI | 具备真实 WebGL 环境，固定字体、DPR 与画布尺寸 |
| 高 | 进一步按目标分段更新 GPU 缓冲 | 先测上传占比，确保实例数量变化不破坏排列 |
| 中 | 图集局部上传或多页图集 | 先测首次字体切换延迟及显存，建立容量指标 |
| 中 | Worker 专用字体加载入口 | 由使用方提供可用字体资源，加载完成后失效旧字形缓存 |
| 中 | 业务更新背压与可观测队列 | 明确吞吐/延迟目标，不把设定 16ms 当成真实完成周期 |

当前保留低层 API 与兼容实现。未来新增内部类默认不进入公开导出，只有稳定且有消费场景的能力才升级为公共接口。
