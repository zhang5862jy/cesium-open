# 椭圆文字增量绘制

`CircleTextData` 保持直接赋值、`edit()`、`expire()` 和 `expired` 用法。
渲染器订阅变更并请求一帧，多个属性写入合并为一次处理。原地修改
`ellipseOffset.x`、`label.fillColor.red` 等嵌套对象后仍需调用 `expire()`。

- 静止且相机高度不变时，不扫描 Data，不重新打包或上传椭圆。
- 文字与椭圆分别标脏；仅修改文字不会上传椭圆实例。
- 同一纹理使用稳定槽位。稀疏修改上传对应槽位，相邻槽位合并；脏槽位
  超过半批或 64 个时采用整批上传，限制 WebGL 调用数量。
- 显隐直接更新实例标志；整桶隐藏时跳过上传与绘制，恢复时同步积累的修改。
- 每个纹理桶按实际数量分配容量并倍增扩容，空桶释放纹理和实例缓冲。
- 缓存每个实例的包围球。位置、尺寸或偏移变化时重新合并该桶包围球，
  旋转、文字、显隐更新无需重新计算整桶包围球。

边界：新增、删除或切换纹理仍会重新分组和打包；相机高度变化仍需检查
文字高度阈值；位置变化后的包围球合并仍与该桶目标数相关。隐藏的目标保留
槽位以避免反复分组，部分隐藏时仍占用实例顶点处理。

运行 `pnpm dev`，打开 `/scripts/circle-text-regression.html` 可执行真实 WebGL
回归。覆盖 1000 个实例的局部上传字节数、纯文字修改、相邻脏区合并、显隐、
嵌套属性过期、纹理切换、扩容、资源释放与渲染请求合并。此验证衡量上传量与
正确性，不代表特定硬件上的 FPS 提升比例。
