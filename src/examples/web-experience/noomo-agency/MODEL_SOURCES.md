# Three.js model sources

The local demonstration uses the following public GLB endpoints discovered from
the Noomo Agency homepage network requests:

- `https://noomoagency.com/newModels/Platform-O.glb`
- `https://noomoagency.com/newModels/Clouds.glb`
- `https://noomoagency.com/newModels/Jellyfish.glb`

The files were retrieved on 2026-07-29 and stored under
`public/noomo-agency/models/` so the example does not depend on the source
website at runtime.

The models are used only for this local visual reproduction/demonstration.
Copyright and other rights in the original models remain with their respective
owners.
